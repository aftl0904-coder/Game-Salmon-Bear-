# 鮭鮭熊

超任風雙人過關。《第一關・溪流小路》HARD，約 3 分鐘一 round。

## 操作

| 玩家 | 角色 | 移動 | 攻擊 |
|------|------|------|------|
| P1 | 鮭男 | `W A S D` | `F` / `空白`（鮭魚彈，傷 1） |
| P2 | 熊女 | `← → ↑` | `L` / `Enter`（控笑臉熊拍擊，傷 2；熊女跟在熊後方） |

- **目標**：前進溪流 → 避開刺坑 → 打倒關底「醃鮭魚武者」→ **兩人一起**站上祭壇
- **R**：重來
- **HARD**：3 心、刺坑傷 2、精英怪傷 2、橋更窄、怪更多；開場僅約 1.2 秒無敵
- 打擊有 hitstop／粒子；走路／跳躍有動態；敵人變紅才會咬（一回合咬一次）
- 首次按鍵後播放 8-bit 風 BGM 與音效（瀏覽器需手勢解鎖音訊）
