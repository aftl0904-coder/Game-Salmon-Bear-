# 鮭鮭熊

超任風雙人過關。全故事五關（見 `STORY.md`）；**目前可玩第 1 關・溪流小路**。

> **QA handoff:** engineer self-check until Visual / Feel / Fun each ≥7.5; overall ~8.0+ before user fine-feel. See [`QA_HANDOFF_GATE.md`](./QA_HANDOFF_GATE.md).

角色：**倫寶（Lun Bo）**、**琪寶寶（Ki Bobo）**、守護靈 **噗噗（Pooh）**（AI，非玩家操控）。

## 流程

讀取 → Logo（約 5 秒）→ 選單（1P／2P・高分榜）→ 進關

## 操作

側視 **上／中／下** 三線（同 X 進度、不同垂直軌道）。攻擊／受傷**只在同線命中**（上下唔啱位打唔到）。

| | 角色 | 左右 | 換線 | Ａ／Ｂ／Ｘ／Ｙ |
|--|------|------|------|----------------|
| P1 | 倫寶 | `A`／`D` | `W`／`S`（上／下） | `J`／`K`／`U`／`I`（攻擊／跳／攻擊／攻擊） |
| P2 | 琪寶寶 | `←`／`→` | `↑`／`↓` | 數字鍵 `1`／`2`／`4`／`5`（攻擊／跳／攻擊／攻擊） |
| AI | 噗噗 | — | 跟琪寶寶所在線 | 始終跟隨琪寶寶 |

- **1P**：控倫寶，琪寶寶 AI 跟隨並對齊倫寶線（電風扇 **1.5×** 移速）；噗噗跟琪寶寶線
- **2P**：雙人鍵盤；兩人可同距離、不同線同時打不同敵人
- 琪寶寶受傷 → 噗噗噴出蜂蜜噴流（仍持續跟隨）
- 收集春蜜罐、打倒關底武者、**兩人站上祭壇**通關（分數寫入 localStorage）
- 通關／倒下後按 **R** 回選單
- **除錯疊圖**：進關後按 **F1** 或 **\`**（Backtick）開關 — 顯示 hitbox、腳底、速度向量、敵人狀態
