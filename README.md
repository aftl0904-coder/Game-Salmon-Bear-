# 鮭鮭熊

超任風雙人過關。全故事五關（見 `STORY.md`）；**目前可玩第 1 關・溪流小路**。

角色：**鮭男**、**熊女**、守護靈 **笑臉熊**。

## 流程

讀取 → Logo（約 5 秒）→ 選單（1P／2P・高分榜）→ 進關

## 操作

| | 角色 | 移動 | Ａ／Ｂ／Ｘ／Ｙ |
|--|------|------|----------------|
| P1 | 鮭男 | `WASD` | `J`／`K`／`U`／`I`（攻擊／跳／攻擊／攻擊） |
| P2 | 熊女 | `←→↑` | 數字鍵 `1`／`2`／`4`／`5`（攻擊／跳／攻擊／攻擊） |
| AI | 笑臉熊 | — | 始終跟隨熊女 |

- **1P**：控鮭男，熊女 AI 跟隨（電風扇 **1.5×** 移速）；笑臉熊跟著熊女
- **2P**：雙人鍵盤；角色可重疊、互不推擠
- 熊女受傷 → 笑臉熊噴出蜂蜜噴流（仍持續跟隨）
- 收集春蜜罐、打倒關底武者、**兩人站上祭壇**通關（分數寫入 localStorage）
- 通關／倒下後按 **R** 回選單

## 敵人（各有存在目標：阻止玩家奪回春蜜／抵達祭壇）
