# 鮭鮭熊

超任風雙人過關。全故事五關（見 `STORY.md`）；**目前可玩第 1 關・溪流小路**。

## 流程

讀取 → Logo（約 5 秒）→ 選單（1P／2P）→ 進關

## 操作

| | 角色 | 移動 | 攻擊 |
|--|------|------|------|
| P1 | 鮭男 | `WASD` | `F`／空白 **鮭魚槍** |
| P2 | 熊女 | `←→↑` | `L`／`Enter` 扇擊（**更快**，背後扇風）；受傷時寵物熊 **蜂蜜噴流** |

- **1P**：控鮭男，熊女 AI 跟隨  
- **2P**：雙人鍵盤  
- 收集蜂蜜罐、打倒關底、**兩人站上祭壇**奪回春蜜  
- 通關／倒下後按 **R** 回選單  

## 執行

```bash
npm install
npm run dev
```
