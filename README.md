# 鮭鮭熊

超任風雙人過關小 Demo（約 30 秒可通關）。先玩、再調。

## 操作

| 玩家 | 角色 | 移動 | 攻擊 |
|------|------|------|------|
| P1 | 鮭男 | `W A S D` | `F` 或 `空白`（遠一點、傷 1） |
| P2 | 熊女 | `← → ↑` | `L` 或 `Enter`（近、傷 2） |

- **目標**：兩人一起站上右側「祭壇」
- **R**：重來
- 血量少、敵人會先變紅再咬（偏吞食天地節奏）

## 本機執行

```bash
npm install
npm run dev
```
