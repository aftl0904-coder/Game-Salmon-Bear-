# 鮭鮭熊

超任風雙人過關。全故事五關（見 `STORY.md`）；**目前可玩第 1 關・溪流小路**。

## 流程

讀取 → Logo（約 5 秒）→ 選單（1P／2P・高分榜）→ 進關

## 操作

| | 角色 | 移動 | Ａ／Ｂ／Ｘ／Ｙ |
|--|------|------|----------------|
| P1 | 倫寶 | `WASD` | `J`／`K`／`U`／`I`（攻擊／跳／攻擊／攻擊） |
| P2 | 奇寶寶 | `←→↑` | 數字鍵 `1`／`2`／`4`／`5`（攻擊／跳／攻擊／攻擊） |

- **1P**：控倫寶，奇寶寶 AI 跟隨（電風扇 **1.5×** 移速）
- **2P**：雙人鍵盤；角色可重疊、互不推擠
- 奇寶寶受傷 → 噗噗（Pooh）從畫面外衝入 → 蜂蜜噴流 → 離場
- 收集春蜜罐、打倒關底武者、**兩人站上祭壇**通關（分數寫入 localStorage）
- 通關／倒下後按 **R** 回選單

## 敵人（各有存在目標：阻止玩家奪回春蜜／抵達祭壇）

| 類型 | 目標 |
|------|------|
| 路障 | 切斷右進路線 |
| 追擊 | 咬住最近／領先玩家 |
| 伏兵 | 平台靜候突襲 |
| 守蜜 | 守護春蜜罐 |
| 精銳 | 玩家推進時插隊干擾 |
| 武者 | 關底三階段頭目 |
