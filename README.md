# 鮭鮭熊

超任風雙人過關。全故事五關（見 `STORY.md`）；**目前可玩第 1 關・溪流小路**。

## 流程

讀取 → Logo（約 5 秒）→ 選單（單人／雙人）→ 進關

## 操作

| | 角色 | 移動 | 攻擊 |
|--|------|------|------|
| １Ｐ | 鮭男 | `WASD` | `J`／`K`／`U`／`I`（Ａ／Ｂ／Ｘ／Ｙ）**鮭魚槍**（`K` 亦可跳） |
| ２Ｐ | 熊女 | 方向鍵 | 數字鍵 `1`／`2`／`4`／`5`（Ａ／Ｂ／Ｘ／Ｙ）扇擊；**移速×１.５（電風扇）**；受傷時笑臉熊從畫面外衝入 **蜂蜜噴流** 後離開 |

- **單人**：控鮭男，熊女 AI 跟隨  
- **雙人**：雙人鍵盤（鍵位不衝突）；角色可重疊  
- 收集蜂蜜罐、打倒關底、**兩人站上祭壇**奪回春蜜  
- 通關分數寫入本機高分榜；通關／倒下後按 **R** 回選單  

## 執行

```bash
npm install
npm run dev
```
