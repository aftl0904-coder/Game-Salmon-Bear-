# 鮭鮭熊

超任風雙人過關。全故事五關（見 `STORY.md`）；**目前可玩第 1 關・溪流小路**。

故事：△**三角組織**大頭目雇來雜魚當 **傀儡**，搶走祭典的 **蜂蜜** 與 **鮭魚**——倫寶／琪寶寶／噗噗要一關一關奪回來。

角色：**倫寶（Lun Bo）** 鮭魚槍（有射程）、**琪寶寶（Ki Bobo）** 劍＋電風扇移速×1.5、**噗噗（Pooh）** AI 跟在琪寶寶**身後**，她受傷才噴蜜反擊。

## 流程

讀取 → Logo（約 3 秒／可跳過）→ 選單（1P／2P）→ 進關（說明可跳過／約 4 秒自動開始）

## 操作

側視 **上／中／下** 三線。攻擊／受傷**只在同線命中**。

| | 角色 | 左右 | 換線 | 攻擊／跳 |
|--|------|------|------|----------|
| P1 | 倫寶 | `A`／`D` | `W`／`S` | `J` 鮭槍（射程有限）／`K` 跳 |
| P2 | 琪寶寶 | `←`／`→` | `↑`／`↓` | `1` 劍撃／`2` 跳 |
| AI | 噗噗 | — | 跟琪寶寶線、跟在**身後** | 琪寶寶受傷 → 蜂蜜噴流 |
