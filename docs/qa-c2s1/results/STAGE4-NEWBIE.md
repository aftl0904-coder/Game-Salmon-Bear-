# 階段四：新手玩家（零背景）

假設從未見過說明，只憑畫面同操作。

## 見到咩
一入關係夜景商場中庭、玻璃圓頂、有「中庭裝置」標籤。腳下有黃字「小心地滑」，之後仲彈大黃條「新機制：地滑！地面閃就會加速」。右邊已經見到「茶餐廳」舖頭招牌同條紋遮陽篷。上面 HUD 寫「大陸2 · 第一關 · 購物中心」。

## 以為要做咩
以為要向右走、打怪、睇地滑告示就唔好亂衝。見到金幣同蜜罐就想拾。第一個「存檔點」以為係商店，入唔到搶答有啲意外；行遠啲先見到「會員中心・搶答」。

## 邊度卡住／唔明白
- 地滑教完之後，地下雜物暫時睇唔到，之後突然有「雜物」尖角，未見過說明會踩中先知要跳。
- 電梯門行近會突然黑場過場，第一次會嚇一跳，唔知可唔可以 Skip。
- 金魚眼一入嚟係說明頁，右邊有大紅掣，但對手係邊個一開始唔知；假對手搶答時畫面寫「對手搶到」先明。

## 幾時想放棄
若果假對手成日搶先、自己淨係輸氣氛，玩兩局或會想 Skip 整局測驗繼續打關。舖頭同走廊視覺已經夠「商場」，唔會因為「唔知自己喺邊」放棄。
