# 第8關：文件櫃怪動畫初稿 QA

`public/art/stage8/enemies/s8cabinet-draft.png` 是待審初稿，並非已完成遊戲整合的素材。大小 3072×704、12 欄×2 行，共 24 格；每格 256×352、res4（邏輯格 64×88），對應 `.json` 提供 idle、walk、warning、attack、hurt、defeat 六組各四格。待機本體約 56 邏輯 px，符合「約 56px」目標；fps 只是建議。

警告已由原版「只開頂層抽屜」改成整片門側開。為減少舊候選開門時身體和雙腳突然變闊，第一格沿用待機，其後三格使用另一張 AI 生成門圖與待機身體合成；該中間版本待機高 50px，再以最近鄰按基準由 50 放大至 56 邏輯 px，沿用其他原有 56px 動作。其他動作來自原始大圖，為保留攻擊第三格完整，該格有約 3.44 邏輯 px 水平補償。各來源及量度見 `50px-source-qa.json`、`56px-source-qa.json`；前者不是最終尺寸成品，兩份的 `/tmp` 來源路徑只是當時工作路徑。

**仍未合格的美術問題：**第三預警格右手只露出小段，第四格右臂被門遮住或不可見；最後開門格轉攻擊首格會突然關門、換姿勢，有明顯跳動風險。`warning-to-attack.gif` 把實際 atlas 的預警／攻擊連播，八幀已解碼比對可見像素一致；是否需要補畫銜接及手臂，須 Claude 檢查。不可把此初稿當成已驗收的最終動畫。

原圖不是目標尺寸繪製，而是大圖二值化、按透明間隔切格及大幅縮小；其後 50→56 亦有再次取樣，輪廓細節不可逆損失。現有深色輪廓未逐處驗證 1 邏輯 px。來源低 alpha 暈光已移除。

`image-check.json`：每格四邊透明、alpha 0／255，atlas 共 63 可見色。`browser.txt`、`desktop-*.png`、`mobile-touch-*.png` 為桌面滑鼠及模擬手機純 touch 独立預覽，六組動作均輪播；並非遊戲或真機測試。`build.txt`、`validate-data.txt` 記錄 tsc + Vite 和 10 項資料驗證通過，Vite 有既有大 chunk 警告。尚未驗證遊戲內比例、碰撞、開門銜接、真人及手機真機。
