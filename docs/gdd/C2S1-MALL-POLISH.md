## 目標玩家／體驗

玩過大陸一嘅人；入商場要覺得「新大陸、有商場味、氣氛一路變差」，唔好一開頭就陰森到尾。

一句話：**光猛中庭 → 扶手電梯／電梯過場 → 陰森走廊 → 恐怖／警報，中間可選入樓層掣房換金幣。**

## 核心改動（本輪必做）

### A. 氣氛三段（光 → 陰 → 恐）

| 段 | 約位置（現有 segment） | 感覺 | 實作（2D，唔轉真 3D） |
|---|---|---|---|
| 光 | A 中庭 + B 前半 | LED、玻璃、暖白 | 亮曝光、淡色遠景、少 vignette |
| 陰 | B 尾 → 電梯後 → C | 燈壞、冷色 | 電梯假 3D 過場後：暗角、冷色 wash、遠景轉暗 |
| 恐 | D 工場 → E Boss | 警報紅閃 | 紅脈衝 vignette、警報音、掃描線可選 |

### B. 電梯假 3D 過場（同意方案）

- 觸發：行到指定 X（建議 A→B 尾或 B→C 交界）踩入電梯門。
- 畫面：鎖鏡、簡短廂內（左右牆透視線＋樓層數字跳 B1→B2／M），3–5 秒，可 Skip。
- 出閘：落地點已係「陰」段參數。
- **唔**整隻關轉 Three.js。

### C. 樓層掣迷你房（同意方案）

- 入口：走廊上「水管／維修門／樓層圖」prop；**可選**（唔入都過到關）。
- 房：單屏、鏡頭鎖死；一面牆有 3–4 個樓層掣（顯示圖示：中庭／停車場／會員中心／工場）。
- 正解：按「B2 停車場」（或畫面上告示寫明嘅掣）。
- 錯掣：怪聲＋小傷害或短暫暗場（唔即死）。
- 獎勵：限時內一次過 → 金幣 ×2；普通出 → 普通幣堆；失敗仍可出房。
- 出房：返原走廊入口旁。

### D. 必修手感／Bug（你已點名）

1. **踎低射擊**：`muzzleY` 踎低時明顯低過企射（建議約再低半個 hitbox／`displayHeight * 0.25`），可射到較低目標。
2. **追兵（魚／松鼠感）死亡**：清走「鮑魚／鬼影 1 秒」——死亡幀／殘影／掉落 FX 對齊；死完唔留怪形體。
3. **追兵 AI**：唔好淨係直線撞；加短預兆（停半拍／低頭）再衝，或小幅左右晃再衝。
4. **舖頭樣**：現有 `s6-shop-a/b/c` 加強可讀性（櫥窗、招牌塊、門口），或換／重排 prop，令走廊一眼係舖頭唔係色塊。

### E. 商場元素（本輪輕量）

必加 prop／佈景（仍 2D）：
- 中庭節日／打卡裝置（A）
- 扶手電梯剪影或可踩短斜台（過場前視覺）
- 會員服務／積分換領櫃台剪影（近迷你房入口）
- 樓層圖／停車場標示牌

本輪**不做**完整：港鐵接駁、空中花園、育嬰室、EV 充電站玩法（可留作遠景貼紙）。

## F. 娛樂金魚眼式・商場搶答（新增，Alan 提議）

### 參考感覺（娛樂金魚眼）
- 題目突然落下、要**鬥快搶答**
- 短題、節奏快、氣氛嘈少少好玩
- 唔係慢慢讀書——答錯有代價、答啱有獎
- 本 game 落地：商場廣播突然「叮——物業小測驗！」畫面停、出題

### 每局規則（草案）
| 項目 | 設定 |
|---|---|
| 題數 | **固定 7 題**／一局 |
| 題庫 | ≥ **70 題**，每局隨機抽 7（最後一題只從「難題池」抽） |
| 類型 | ① 地產／物業管理／租務**簡化常識** ② **快計數**（租金、按金、管理費等） |
| 形式 | 四選一（A/B/C/D），適合手掣／觸控 |
| 搶答 | 1P／2P 各自撳「搶答掣」；**先搶者**先有 3 秒作答窗；錯則短暫鎖、對手可搶 |
| 單人 | 對住限時；唔搶對手，淨係同倒數鬥快 |
| 獎懲 | 啱 → 該玩家**加金幣**；錯 → **扣金幣**（扣到 0 為止，唔欠債） |
| 第 7 題 | 難題；分數／金幣 **×2**（或專用高分表） |
| 可略過 | 整局開始前 2 秒可 Skip（唔想玩測驗）；Skip＝冇獎冇罰 |

### 建議分數（可用幣）
