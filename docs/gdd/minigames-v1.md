# 4. 評級模擬

**假設 ★**
- 每個遊戲3段，每段4次機會，總共12次。
- 時機類：新手按掣誤差 σ＝110ms，普通 σ＝70ms，已計手機觸控。
- 其他類：新手每段成功率約90%→75%→58%，普通約97%→88%→76%。

**結果：一套門檻做唔到同時「新手30%金、普通60%金」。** 新手同普通差距太大；門檻調到新手約30%時，普通會有74–89%金。我建議**以新手30%為準**，因為主要玩家係琪琪。

| 類型 | 建議 | 新手：金／銀／銅 | 普通：金 |
|---|---|---|---|
| 時機 | 時間窗 280／200／150ms；12次中9次成功先係金 | 33%／59%／8% | 89% |
| 平衡 | 9次成功先係金 | 33%／65%／2% | 80% |
| 瞄準 | 9次成功先係金 | 24%／73%／3% | 74% |
| 記憶 | 9次成功先係金 | 34%／64%／2% | 83% |
| 解謎 | 9次成功先係金 | 29%／69%／2% | 80% |
| 反應 | 10次成功先係金 | 43%／56%／1% | 87% |

- **時機類要加闊時間窗。** 如果用較窄嘅 220／160／120ms，新手金只有12%，銅反而有27%。
- 反應類用10次成功先係金，新手金係43%；用11次就跌到18%。12次機會嘅情況下冇辦法再微調，所以**建議用10次**，寧願易少少。
- 銀級門檻建議定喺6次成功。按呢個門檻，新手銅級只有1–8%，略過嘅人一樣當銅級。
