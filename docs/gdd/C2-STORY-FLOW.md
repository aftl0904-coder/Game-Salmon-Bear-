## 3. 建議故事脊柱（令完整度 ↑）

### 一句話（大陸2）

野餐以為完咗，其實 △畝仲有 **「百畝商場・森友展銷」**——用展銷會包裝，把森林朋友變成「可購買嘅產品」；噗噗認到味道，先係引路，再係自己衝入去救。

### 三條線（對齊 bible，續寫）

| 線 | 大陸2 點收 |
|---|---|
| **救噗噗** | 唔係再餵蜜；而係 **陪佢搵返被展銷走咗嘅同伴氣味**；離隊＝主動救人，唔係消失 |
| **救小朋友** | 展銷籠＝新形態蜜箱；通關／反應點救到或確認「仲未賣出去」 |
| **三角／△畝** | 商場（ST-06）＝門面＋保安；展銷（ST-07）＝ **二期銷售話術**（產品化蜜僵） |

### 建議過場節拍（唔改玩法，只定文案／cutscene）

```
[已有] C2_INTRO 野餐 → 商場門前
[建議加薄] ST-06 開頭／中段 1 句：廣播「森友展銷・今日試業」或廣告牌
[建議加] ST-06 清關短卡：搵到傳單／樓層圖「往・森友展銷中心」
[重寫] ST-07 開場：呢度唔係行街，係展銷會；籠喺玻璃後面扮「展示」
[保留加強] D 段噗噗反應：認到同伴氣味（具體一種氣味／一個名更好）
[重寫] 馴獸師 Boss 卡：受害者（例如被送「教鞭／徽章」要令展銷「零退貨」）
[重寫] Boss 後：噗噗離隊去追味；倫／琪約「我哋喺出口等你／一齊走」
[建議加] ST-07 清關：馴獸師醒返一句＋展銷暫停；指向下一未做關或「未完」字卡
```

### 馴獸師（已有卡・建議補齊演出）

`data/bosses.json` 已有受害者骨架：**飼養員＋鞭＋「聽話先有得賣」＋聽唔到動物喊**；雜兵＝產品化蜜僵／鎖鏈。  

仍欠（令評價完整）：  
- 開場令玩家知「展銷＝賣朋友」；  
- Boss 前卡真係播得出（唔好再「待補」）；  
- 打完醒返 **一句對白**（開閘／道歉／指路）；  
- 同噗噗離隊鉤埋（佢追嘅味＝籠裏同伴）。

### 點解可能「評分高過第一集」

大陸一強喺關卡花樣；弱喺後期有時似「打完再打」。大陸二若做到：

1. **一句聽得明嘅新邪惡**（把朋友當貨）；  
2. **噗噗有主線主動**（唔再淨係跟）；  
3. **Boss 醒返有溫情**（延續第一集最好嘅規則）；  
4. **關與關有物件鉤**（傳單／樓層圖／氣味）——  

評價會跟「完整故事」走，而唔淨係「手感」。
