## 交付

`public/art/stage9/enemies/s9chief.{png,json}`：原創灰髮中年獄卒、巡護員制服、腰間大串鎖匙及警棍。48 格／12×4；每格 256×224、`res: 2`，邏輯格 128×112，待機可見高度約 71–72 邏輯 px。動作依次是待機、舉棍預警、橫掃、擲匙預警、擲匙、落閘預警、落閘手勢、甩匙、弱點發光、受傷、倒下、開籠手勢。開籠只有人物轉匙手勢，沒有籠或鎖圖；落閘只有人物手勢，沒有閘的動畫。

三張 1920×1920 透明原稿經 AI 修正多餘鎖匙；統一縮放、透明切格、色盤量化及 nearest 放大。修正版 A 最頂部有一條不屬人物的雜點帶，裁掉最上 35px 後打包；各格來源／分格方法及 SHA-256 見 `source-report.json`。原稿只保留於暫存目錄、未入 repo；輸出是圖片素材而非遊戲玩法。擲匙原稿的第 17 格仍有腰間及手上兩串匙；落閘第 27 格腰匙消失，故 JSON 刻意不用 16、17、27 格，並以 `[18,19,19]`、`[24,25,26,26]` 播放相應動作：會有直接切格，並非補出平滑過渡。掉匙／弱點格的腰匙已移除、地上鎖匙仍在；弱點黃光較細，遊戲實際大小是否足夠清楚仍需驗證。
