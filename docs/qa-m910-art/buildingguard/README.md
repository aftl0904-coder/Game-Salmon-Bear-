# 第10關大廈保安：美術及 QA（2026-11-25）

## 交付

`public/art/stage10/enemies/s10buildingguard.{png,json}`：原創小型人類保安，藍色制服、無字塑膠盾。24 格、12×2、RGBA 3072×704；每格 256×352、`res: 4`，邏輯畫布 64×88，待機可見高度約 48 邏輯 px。動作有待機、行、衝撞預警、衝撞、受傷、倒下。

原始 4×6 角色圖的行走各格步幅近似，AI 修改未能清楚交替；另畫 2×2 行走原稿，四格為兩個跨步與兩個收腳姿勢，以統一比例替換圖集中 4–7 格。補畫格可見步幅變化，但左右腳交替無法可靠辨認，不能聲稱解剖上完美交替。兩張源圖在暫存目錄，未入 repo；來源雜湊、切格、比例、色盤及輸出雜湊見 `source-report.json`，工具 `prepare-sheet.py`、`prepare-buildingguard.py` 僅切割、排列、重取樣及量化已有圖像。素材底線並非遊戲世界錨點。

原圖第 10 格盾在頭側、第 12–13 格後仰；JSON 預警使用 `[8,9,9,11]`、衝撞使用 `[14,15,15]`，跳過問題格但會直接切格，移動／推進由遊戲處理，不能單靠素材承諾。

## 驗證

- `build.txt`：tsc + Vite build 通過；`validate-data.txt`：13 項通過；`image-check.txt`／`.json`：24 格非空、格邊透明、二值 alpha、≤64 色、索引合法。
- `preview-warning-attack/`、`preview-idle-walk/`：以 JSON 實測桌面滑鼠及模擬手機 touch 預警→衝撞、待機→行走，名義格序／FPS 通過並留截圖及 trace；不是遊戲內實際動畫驗收。
- `game-desktop/`：現有第4關桌面 smoke 通過；`game-mobile/`：三款橫向手機純 touch 控制通過，直向只測轉向提示。以注入方式到達測試點，非完整通關或真機。
