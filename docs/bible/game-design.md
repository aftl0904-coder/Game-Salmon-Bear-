### 主線（玩家感受到嘅故事）
1. 野餐日，噗噗食咗三角組織派嘅「假蜂蜜」，變成灰色、軟晒、得返一副空殼。
2. 咖啡媽媽話：只有五罐「真蜂蜜」救得返佢，而五罐都俾三角組織搶咗，分開收喺五個地方。
3. 每關搶返一罐；每罐落肚，噗噗就回復少少顏色同動作（每關之間嘅過場會見到）。
4. 第 5 關揭穿：三角組織 = 地產商「△畝發展」，用假蜂蜜令森林動物變「蜜僵」，好清場起商場。
5. 結局：噗噗完全醒返，森林保住；最後一句說話（待補）。

## 2. 五關設計

每關固定結構：**教 → 試 → 休 → 變 → Boss 前休 → Boss**。每關只加一個新機制。

### 第 1 關・百畝樹林（野餐入口）★
- **主題／情緒**：明亮、輕鬆，但有不安伏筆（遠處「△畝發展・即將動工」廣告牌、樹上有三角形記號）。
- **場景**：遠景湖光山色（現有）；中景樹叢（現有）；近景野餐布、樹樁、燈籠；黃昏前嘅暖光。
- **新機制**：跳坑、台階、木板（已完成）；打爛燈籠／瓦罉出寶（開發中）。
- **敵人**：紅魚（衝刺）、帽仔兵（拋石）、機械豬（鐵甲，只做守衛）。
- **Boss**：無；終點係「祭壇伏兵」一波戰。
- **隱藏**：木板上嘅蜂蜜；一個要打爛三個燈籠先出現嘅金鮭。
- **3 秒彩蛋**：無（教學關）。

### 第 2 關・蜜樹丘（樹冠）★★
- **主題／情緒**：好奇、壓迫感開始；樹冠入面光線斑駁，有蜂嘅嗡嗡聲。
- **場景**：巨樹內外，藤蔓、蜂巢牆、陽光光柱（code 做光柱同飄浮花粉）。
- **新機制**：**移動木板**＋**風口**（琪寶寶紙扇喺風口可以飄高）。
- **敵人**：蜜蜂（飛行、俯衝，蹲低避）、帽仔兵、新敵人「蜜僵松鼠」（被假蜜控制，慢但成群）。
- **Boss：蜜冠女王蜂**（3 階段）
  1. 喺空中左右飛，放蜂群（三隻一組直線飛過）；
  2. 落地產卵，卵會孵出小蜂，要先打卵；
  3. 噴假蜜泉（地面變黏，行慢），弱點：噴完之後頭頂發光 2 秒。
- **過場**：打贏後女王蜂醒返，警告「溫泉嗰邊有行路唔穩嘅動物」。
- **3 秒彩蛋**：Boss 第 3 階段，撳「攻」打斷假蜜泉 → 掉金鮭。

### 第 3 關・月影夜市＋溫泉 ★★★
- **主題／情緒**：詭異。夜市燈籠一盞盞自己熄，攤檔冇人但鑊仲喺度炒。食嘢（夜市、龍蝦、油甘魚）喺呢關出場。
- **場景**：夜市街（攤檔、燈籠串、煙霧）→ 溪橋 → 溫泉（蒸氣、霧、倒影）。code 做：燈籠光暈、蒸氣粒子、水面倒影、燈光閃爍。
- **新機制**：**熄燈**（燈籠熄咗嗰段畫面變暗，只見主角周圍）＋ **溫泉滑地**。
- **敵人**：龍蝦兵（雙鉗，前方格擋，要跳過去打背）、油甘魚攤主（喺攤檔後面掟刀，攤檔可以打爛）、鏡影雜兵（真假分身）。
- **道具**：油甘魚刺身＝回 2 格血；龍蝦＝攻擊力 ×1.5，10 秒。
- **Boss：月橋鏡鴞**（3 階段）
  1. 羽幕（一排羽毛由上跌落，留一條縫）；
  2. 分身：三隻鏡鴞，只有一隻喺水面有倒影；
  3. 鎖箱：鏡鴞守住鮭箱，打箱同時打佢。
- **過場**：的士嚟接（咖啡媽媽喺車上遞熱咖啡）。
- **3 秒彩蛋**：夜市「搶最後一隻龍蝦」——3 秒內撳「攻」，成功得龍蝦。

### 第 4 關・鹽霧工地（午夜公路）★★★★
- **主題／情緒**：最恐怖嘅一關。濃霧、警示燈、喪屍感嘅「蜜僵」；返工嘅壓迫感（打卡鐘、文件堆）。
- **場景**：工地（吊臂、推土機剪影、鐵網）→ 午夜公路 → 工地寫字樓。code 做：霧、雨、警示燈旋轉、閃電剪影。
- **新機制**：**電單車追逐段**（自動前進，只需要跳同射）＋ **天花尖刺塊**。
- **敵人**：蜜僵（喪屍式，慢、成群、被打會流假蜜）、的士怪（高速衝刺）、打卡鐘怪（定時炸開文件）、推土機（背景衝過，要跳上平台避）。
- **喪事班車（尊重處理）**：霧中一架安靜嘅班車慢慢駛過，冇敵人、冇音樂，只有引擎聲同雨聲，玩家要等佢過咗先行；之後蜜僵數量減少（暗示佢「帶走」咗啲迷失嘅靈魂）。唔嘲諷，可以喺設定關閉。
- **Boss：泥鬃（電單車工頭）**（3 階段）
  1. 騎電單車來回衝撞（跳過）；
  2. 召喚蜜僵潮，同時喺高台射釘；
  3. 落車肉搏，披風上嘅蜜印係弱點。
- **過場**：泥鬃電腦入面見到「清拆百畝・假蜜量產」電郵，指向主控室。
- **3 秒彩蛋**：電單車段「閃避迎面班車」——3 秒內撳「跳」。

### 第 5 關・蜂巢冠主控室 ★★★★★
- **主題／情緒**：決戰。巨型蜂巢入面接滿電線同屏幕，紅色警報燈；最後放晴。
- **場景**：蜂巢通道（六角形牆、流動蜜）→ 主控室（大屏幕播簡報）。code 做：屏幕閃動、蜜流動、警報燈、最後陽光衝入嚟。
- **新機制**：所有機制混合；**溫泉回復點**（Boss 前全回血）。
- **敵人**：前四關精英版各一（精英頭上有三角記號）。
- **Boss：△畝大佬**（3 階段）
  1. 假蜜雨＋蜜僵門；
  2. 推土機軌道＋舊 Boss 投影；
  3. 三角盾＋主控電腦弱點；噗噗醒咗一半，最後一擊由噗噗合體出手。
- **結局**：見第 4 節。
