## 3. 洗地機 Boss（以下整節為建議，待 Alan 確認，非實作指示）

### 範圍與機器可讀性

已確認它是銀灰及深藍、前方有鏡頭與轉刷的大型商場洗地機；其餘原創造型細節由 Cursor 發揮，圖中不能有品牌或文字。燈光／聲效的遊戲表現、機器名稱及具體戰鬥數值仍未定；**不得假定駕駛員、人格、受控制、主人、故障原因或陰謀**。可提議用不同鏡頭方向、地面輪廓和刷子朝向說明危險；不要只靠紅／綠分色。

### 建議狀態機：偵測 → 固定預警 → 有效攻擊 → 解除傷害 → 恢復 → 再偵測

1. **偵測／移動**：鏡頭轉向最近有效玩家，保持距離以便看見完整機身；玩家暫時離開範圍則繼續巡視，不立即打。目標選取建議重用 `pickTarget`，2P 同距採穩定規則；失效目標再選取但不取消已出現的完整預警。
2. **預警**：鏡頭停定並顯示方向，機身後仰／刷罩上提，地面顯示與攻擊碰撞一致的預警區。**預警開始鎖定方向與危險區**，不要追蹤另一名玩家或在最後一幀轉向；預警非傷害。若有效目標消失或場地變窄而安全路徑不足，取消／重新完整預警。
3. **衝撞**：沿鎖定方向行有限距離，只有明示有效區有傷害；到距離上限或場邊停止，不越過場界、不將人擠出畫面。機身和碰撞框同步，與提示區不矛盾。
4. **近身轉刷**：只在近距離選擇；先可見刷子升起／轉動預備，然後固定範圍短暫旋轉，刹停後立刻移除傷害，不吸人、不追蹤、不全場掃蕩。預警區必須覆蓋所有實際刷子 hitbox。
5. **恢復／可反擊**：每次衝撞**或**轉刷都先完全停止傷害，再進入可被一般遠程與近戰攻擊命中的明顯恢復；受擊閃光不掩蓋狀態。恢復期不可插入新攻擊／無人機／傷害地板。重新偵測後才進下一輪。
6. **phase／中斷**：跨血量門檻、擊退、死亡或暫停時先取消／清理活動 hitbox 和提示；phase 切換不可縮短已開始預警及恢復，亦不可立即攻擊。死亡只表現機器停機，無人物退場或被控制解除的暗示。
