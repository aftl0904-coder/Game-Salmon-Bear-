## Alan 確認的攜帶規則

- **⚪ 可選**：以大陸1第1關或大陸2第1關（內部第6關）開新本局，可選擇帶或不帶之前的裝備及成長。⚪ 只出現在兩個大陸的第一關「開新本局」入口。
- **✅ 延續**：同一本局按次序過關，沿用該局的裝備及成長；大陸1第5關後按順序進入第6關亦算延續。隔日用已保存本局繼續預期下一關，仍算順序。
- **🚫 強制基準**：直接選第一關以外的其他關開始，一律不帶之前裝備及成長；重玩已通關舊關也一樣。這取代舊方案「重玩可選帶／不帶」。第1或第6關作為開新本局入口時，仍依 ⚪ 規則。
- 跳關／重玩為支線，完成後返回主線預期下一關，不破壞主線。基準＝該關原本起手、沒有舊成長點數及裝備。支線的暫存狀態要與主線隔離，不能為達成基準而刪除舊裝備。
- 舊裝備承接主線，舊 `maxStage−1` 視為已通關；新遊戲保留已通關紀錄及大陸2結局旗標。今次不做清存檔掣。
- 新玩家沒有現有本局及非零舊裝備／成長時，第1或第6關直接以基準開局，不顯示無意義的帶裝選擇。若重開會取代已有進度，本局選擇對話框顯示進度警告，預設選中「取消」。

## 排名資格（Alan 於 2026-11-03 確認）

- 已確認：🚫 基準遊玩可以上排名。排行榜存入與 `clearRank()` 評級是兩件事；不能上排行榜時仍顯示原本通關評級。
- 按開局時**實際帶入**的舊裝備及成長判斷；任何一項非零，該局不寫排行榜。揀「帶」但實際全部為零，仍可上榜；揀「唔帶」或以 🚫 基準開始，也可上榜。
- 同一本局其後順序關卡沿用開局時的排名資格；順序遊玩期間正常取得的裝備／成長不視作開局帶入舊物。
- 舊進度首次遷移至本局時，舊裝備按同一局取得處理，遷移後仍可上榜；玩家另開新局並選擇帶入非零舊裝備則不可上榜。

## PR2 技術及測試方案

- 擬新增 `localStorage` key `sake-kuma-run-v1`，使用版本化 JSON 記錄主線：起始關、最後完成關／預期下一關、裝備快照、成長資料的預留欄位及排名資格；跳關／重玩另用隔離的支線狀態，不能覆蓋主線快照。具體欄位及恢復／儲存失敗處理需先審閱。
- 🚫 支線使用**記憶體 active loadout**：支線期間的裝備、金幣及 HP 變化只屬支線，完成即棄，絕不寫回主線。已通關紀錄及 `clearRank()` 評級共用；支線完成不能推進主線預期下一關。不能靠 `resetGear()` 或覆寫 `sake-kuma-gear-v1` 達成隔離。
- 新遊戲由第1或第6關建立新本局；每次順序通關保存下一關及本局快照，重新開遊戲或隔日回來可繼續。支線完成返回原主線；新遊戲替換本局但保留既有通關紀錄與結局旗標。第10關未實作，整局完成後的收尾留待第10關接線。
- 保留 `sake-kuma-progress-v1`、`sake-kuma-gear-v1`、`sake-kuma-friends-v1` 和 `sake-kuma-c2-cleared-v1` 等原有鍵；首次無 run 時按上面已確認遷移規則承接。必須測有／無舊裝備、損壞／無法寫入資料，不得因基準模式直接 `resetGear()` 而抹掉原裝備。
- 預計修改 `MainMenuScene.ts`、`WorldMapScene.ts`、`GameScene.ts`、`progress.ts`、`gear.ts`、`score.ts` 及新增 run 管理模組；具體以複核現有系統為準。成長點數不在 PR2 實作範圍，只預留欄位。

### 本次實作細節

- `sake-kuma-run-v1` 的版本 1 本局包括獨立 `runId`、`startStage`、`lastCleared`、`nextStage`、`gear`、預留的 `growth`、`eligible`、`coins`、`purse`、`hp`、`friends`、`charm`、`mode`、`solo`。每次順序過關記錄快照；新開局可替換主線，不清舊通關紀錄／結局旗標。
- 從無主線直接玩支線時，本局鍵會記錄 `{"version":1,"noMain":true}`，避免共用的通關進度在重開後誤當成舊主線遷移；標記不是一個可繼續的主線。
- 舊存檔沒有單／雙人模式資料；首次承接時沿用玩家當次選擇。主線先保存後才同步舊裝備鍵；商店購買的扣幣與裝備以同一本局快照保存。存檔損壞、無法寫入，或寫入前發現另一分頁已更新快照時會顯示警告。`localStorage` 的比較及寫入並非原子操作：兩個分頁同時寫入仍有競態，暫不保證多分頁安全，建議只開一個分頁。
- 第5關片尾保留原流程。測試閘關閉時，從支線返回不會繞過閘進入第6關；只有測試閘開啟而主線完成第5關，片尾才提供前往大陸2。
