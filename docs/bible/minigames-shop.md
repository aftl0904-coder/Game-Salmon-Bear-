# 小遊戲、金幣同裝備店

> 由 Alan 2026-10-27 嘅構思整理。未做嘅標住「待做」。

## 1. 總體流程

每一關入面：

```
打機 → 攤檔（小遊戲，賺金幣）→ 裝備店（用金幣買嘢）→ 繼續打 → Boss
```

- 每關**一個攤檔**，攤檔老闆每關唔同（見下）。
- 攤檔打完即刻開店，想儲錢唔買都得，金幣跟住過下一關。
- 遊戲開始前有 **1 至 3 頁講解**：點玩、點樣攞高分。撳一下揭一頁，可以跳過。

## 2. 雙打點玩

**兩個人同時玩同一個小遊戲，左右兩邊各佔半邊畫面。**

- 每人自己一份道具（自己杯咖啡、自己個夾餅）。
- 輸入分開：1P 用 WASD／左邊觸控，2P 用方向鍵／右邊觸控；手掣各用各。
- 分數同金幣**各自計**，唔係夾份，所以邊個叻邊個買得起好裝備。
- 單打就佔返成個畫面。

## 3. 金幣同裝備店

- 金幣由小遊戲、打爛嘢、打低敵人嚟。
- 每個角色**自己一個錢包**，自己買自己嘅嘢。
- 裝備分三級：木 → 鐵 → 金。價錢遞增，升級要逐級升。

| 裝備 | 效果 |
|---|---|
| 劍（琪寶寶） | 攻擊力 +1 / +2 |
| 槍（倫寶） | 一次射兩粒 / 三粒三文魚子 |
| 盔甲 | 傷害 −1（最少 1）／金級再加 1 格心 |
| 鞋 | 行快啲、跳高啲 |
| 護身符 | 被打中之後無敵時間長啲 |

- **死咗**：跌一級（唔係清零），例如金劍跌返做鐵劍。跌到木級就冇得再跌。
- 因為有裝備，起手心心減一格（倫寶 6→5、琪寶寶 5→4），愈打愈強。

## 6. 估字熊仔（大型，排後啲）

噗噗做動作，玩家逐隻字估，講出答案。

- 題目：常見物品、地方、活動、興趣、食物；三至四個字。
- 畫面：噗噗佔成個畫面，估完先返正常遊戲畫面。
- 先講明：有幾多隻字、咩類型。
- 撳第一個字 → 噗噗做第一個字嘅動作（可以係同音字，例如「八」就用手比個 8）。
- 兩粒掣：**棄權** / **作答**。作答用語音講出答案，講啱就贏。
- 限時 1 分鐘，作答唔限次數。

**技術上做唔做到：**
- 語音輸入：Android Chrome 做到，支援廣東話，要上網。
- 隨機出題：唔一定要 AI。噗噗得嗰幾個動作圖，所以**真正嘅樽頸係動作圖，唔係出題**。
- 做法建議：先叫 Cursor 畫一套「做動作」嘅噗噗（數手指 1–10、扮動物、扮形狀、扮動作），
  再寫一本題目簿，每條題目對應一串動作。題目隨機抽，唔使上網、唔使錢、質素可控。
- 真係要用 AI 出題嘅話：要喺 Vercel 開一個後端 function，加一條 API key，每次出題收少少錢。
  可以之後先加，遊戲照樣玩得。
