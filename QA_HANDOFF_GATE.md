# QA handoff gate

Self-estimate scores (honest, not inflated). Engineer-only until gates pass.

| Gate | Threshold | Allowed |
|------|-----------|---------|
| Before basic test / screenshots for user | **Visual**, **Feel**, **Fun** each ≥ **7.5** | Internal self-check only |
| Before handoff for fine issues / feel polish | Overall ~**8.0+** | User-facing review OK |

Until then:

- No inflated scores
- No screenshot spam to the user
- Keep iteration engineer-only
